🧾 Prompt
Este documento proporciona un sistema de información organizado para proyectos de Yar-Yur 2026. En cada día, hay una sección llamada "CARPETAS" que contiene elementos cruciales de cada proyecto.
Estos elementos de proyecto se identifican mediante palabras clave específicas: RENDIMIENTO, VISUAL, PLANO MECÁNICO, MUESTRA, PRODUCCIÓN, AUTORIZACIÓN
Cada elemento sigue un formato estructurado:
* Palabra Clave: Identifica el tipo de proyecto.
* Número identificador: Número entre paréntesis.
* Número de Proyecto:  Número de referencia único.
* Cliente: Nombre todo en mayúsculas entre dos guiones
* Título del Proyecto:  Nombre descriptivo en mayúsculas.
* Descripción del Proyecto: Resumen breve del proyecto.
* Identificador de Trello: caracteres alfanuméricos que identifican el Trello
* Enlace a la Carpeta de Google Drive:  Acceso directo al almacenamiento del proyecto.
* Check de archivos en DRIVE: puede ser LISTO o FALTA
La solicitud es crear tablas para un archivo html que extraigan y presenten los datos de los proyectos de cada día. Las tablas deben tener 8 columnas en este orden: 


* Columna 1: número identificador
* Columna 2: fecha en formato DD/MM/AAAA
* Columna 3: palabra clave
* Columna 4: número de proyecto
* Columna 5: nombre del cliente
* Columna 6: título del proyecto
* Columna 7: Identificador de Trello
* Columna 8: descripción del proyecto
* Columna 9: enlace explícito a la carpeta de Google Drive
* Columna 10: LISTO o FALTA


Organizar las filas de la tabla por número identificador ascendente y por fecha ascendente


Al principio de cada pestaña está especificado los números de las tablas que se deben crear, qué datos deben tener cada tabla, y la cantidad de filas que debe tener cada tabla.
